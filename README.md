# AlgoStudio: Offline Coding Interview Platform & LeetCode-Style Problem Creator

A 100% offline, self-contained coding interview practice environment. Display, retrieve, and create LeetCode-style coding problems with real-time Monaco editor, Python language server, local test case runner, and bulk ZIP import/export.

## Highlights
- **100% Offline**: Zero external network dependencies or CDN calls.
- **LeetCode-Style Practice**: Problem statements, constraints, examples, solutions, collapsible hints, and local test case execution.
- **VS Code Monaco Editor**: Rich syntax highlighting, Jedi IntelliSense autocomplete, hover documentation, real-time AST syntax compiler diagnostics, and Black formatting.
- **Question Storage Engine**: Built-in CRUD persistence and indexing for questions.
- **Question Management Dashboard**: Visual interface to create, update, verify, and organize custom interview problems.
- **Bulk ZIP Import & Export**: Import question packages directly from local `.zip` files into your offline problem library.

## Quick Start
```bash
python3 server/app.py
```
Open [http://localhost:8080](http://localhost:8080) in your browser.
